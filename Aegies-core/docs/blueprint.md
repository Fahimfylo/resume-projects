# **App Name**: AegisCore

## Core Features:

- Secure Binary Analysis: Deep-scan file uploads for malicious double extensions, mismatched magic bytes, and known signature threats within an isolated sandbox environment.
- IntelliLink Scan Tool: An AI-powered tool that analyzes suspicious URLs for phishing patterns and evaluates domain reputation through generative risk assessment.
- Threat Insight Engine: A generative tool that translates complex scanning metadata into human-readable security advisories and personalized defensive actions.
- Live Defense Dashboard: Visualize global threat statistics and scan metrics with a high-fidelity glassmorphism interface featuring animated SVG telemetry.
- Encrypted Scan Archive: Securely persist history, hash values, and risk reports using a cloud-managed MongoDB instance for auditing and trend tracking.
- Heuristic Score Radar: Real-time calculation of risk scores (0-100) based on multiple detection vectors including SHA256 entropy and extension masking.
- MIME-Type Sentry: Automatically validates binary signatures against stated file extensions to identify cloaked executables pretending to be static images.

## Style Guidelines:

- Primary Color: Cobalt Deep Blue (#3B82F6) chosen to represent stability and modern cybersecurity defense.
- Background Color: Obsidian Navy (#0A0C16), a heavily desaturated variant of the primary hue for a sophisticated dark-mode aesthetic.
- Accent Color: Electric Violet (#8B5CF6), providing high contrast against the deep navy background for critical interactive elements.
- Headlines use 'Space Grotesk' for a computerized, tech-centric feel. Body text uses 'Inter' for maximum readability in data-dense reports.
- Code and hash values use 'Source Code Pro' to ensure technical details and binary metadata are clearly distinguishable.
- Highly geometric, thin-stroke monoline icons with subtle glows to maintain the high-tech, futuristic dashboard vibe.
- Micro-interactions utilize Framer Motion for smooth state transitions, featuring pulse animations for critical alerts and scanner progress bars.
