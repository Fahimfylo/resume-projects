Hi there! 👋
This repository contains my top 3 full-stack projects, with live demos and GitHub code.

1. PROSPCT – B2B Lead Database
Tech Stack: React.js, Node.js, Express.js, MongoDB, Redis, Tailwind CSS, Zustand, Socket.io, Stripe, Gemini AI
Description: B2B lead database with 60M+ contacts, 20+ filters, saved lists, auto-enrichment, email verification, CSV/Excel export, team workspaces, and credit-based billing.
Live Demo: https://app.prospct.io
GitHub: This repo (folder: /PROSPCT)

2. AegisCore – Cybersecurity Defense Platform
Tech Stack: Next.js 15, Tailwind CSS, Shadcn UI, MongoDB, Genkit, Gemini AI
Description: AI-powered threat scanning (malware analysis, phishing email & URL detection, website vulnerability scanner), live threat-intel feed, breach checker, and SOC dashboard with MITRE ATT&CK mapping. Includes a Chrome extension and CLI.
Live Demo: https://aegies-core.vercel.app/
GitHub: This repo (folder: /Aegies-core)

3. Campaignforge – AI Campaign Workspace Generator
Tech Stack: React 19, Vite, Tailwind CSS, Express.js, MongoDB, Gemini AI
Description: AI generates complete marketing workspaces (strategy, tasks, content, calendar) from a few business details, with a copilot chat that creates and edits campaign assets in real time.
Live Demo: https://momentum-ai-mocha.vercel.app/
GitHub: This repo (folder: /campaignforge)
